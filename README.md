# Love Is In The Air

Landing page for an app for long-distance couples: interactive dates, a countdown to your next visit, Deep Talks questions, travel planning, and articles.

Plain HTML/CSS/JS with no build step. Open `index.html` in a browser, or view it on GitHub Pages.

## Placeholders to replace before launch
- Prices, book title, and sample articles
- Waitlist form doesn't save sign-ups yet
- Ad slots are labeled placeholders

## Color scheme
Vintage airmail, taken from the hero postcard. Defined once as CSS variables at the top of `index.html`.

| Name | Hex | Used for |
|---|---|---|
| Paper | `#f4e9d4` | Page background |
| Kraft | `#ecdcbf` | Alternate surfaces |
| Notepaper | `#fbf5e9` | Cards and panels |
| Sepia ink | `#2f241b` | Main text |
| Faded ink | `#6b5848` | Secondary text |
| Pencil rule | `#d9c6a5` | Borders and dividers |
| Postmark red | `#a8362f` | Hearts, highlights, labels |
| Airmail navy | `#2c4a7a` | Buttons and links |
| Night navy | `#22344f` | Dark bands (countdown) |
| Rose stamp | `#c98b84` | Soft accent |
| Watercolor sky | `#9fb4c8` | Soft accent |
| Map green | `#7f8f6c` | Soft accent |
| Old gold | `#c3954e` | Soft accent |

Fonts: Young Serif (headings), Figtree (body), IBM Plex Mono (labels and numbers).
